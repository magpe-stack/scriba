🚀 Como Usar o Aplicativo

Digitação Instantânea
Ao abrir a Lousa Rápida, o aplicativo abre direto na área de escrita, pronto para receber digitação ou colagem de texto imediata (sem janelas iniciais ou botões para criar notas).

2. 5 Quadros Independentes (Abas)

O aplicativo disponibiliza 5 quadros empilhados em abas no topo.
Clique em qualquer aba para alternar entre os quadros. Cada quadro salva seu conteúdo de forma independente.
Renomear Abas: Dê um duplo clique sobre o nome de qualquer aba para alterar o título do quadro (ex: Recados, Telefones, Rascunho).
3. Barra de Ferramentas e Recursos

📋 Copiar Texto Limpo: Copia todo o conteúdo do quadro ativo para a sua área de transferência em formato de texto puro.
✨ Limpar Formatação: Remove linhas vazias em excesso e espaços duplicados, deixando seu texto alinhado e limpo.
📞 Destacar Telefones: Detecta automaticamente números de telefone presentes no texto e cria uma lista organizada no final do quadro.
🧹 Limpar Quadro (Lousa Mágica): Apaga todo o texto do quadro ativo instantaneamente. Se você apagar sem querer, basta clicar no botão Desfazer no aviso que surge na parte inferior.
4. Modo Claro e Modo Escuro

Clique no botão Modo Claro / Modo Escuro no canto superior direito para alterar o estilo visual de toda a aplicação (Lousa Branca ou Lousa Escura).
5. Atalhos de Teclado

Ctrl + Shift + C (ou Cmd + Shift + C no Mac): Copia o texto limpo instantaneamente.
Esc: Apaga o quadro atual quando você estiver digitando no campo de texto.
